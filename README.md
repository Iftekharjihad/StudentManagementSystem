# Student Management System (C# Console App)

## 📌 Project Description
This is a simple Student Management System built using C# Console Application. It demonstrates basic CRUD operations and Object-Oriented Programming (OOP) concepts.

---

## 🚀 Features
- Add Student
- View All Students
- Search Student by ID
- Update Student Details
- Delete Student
- Simple Console Menu Interface

---

## 🛠️ Technologies Used
- C#
- .NET Console Application
- OOP Concepts (Class, Object)

---

## ▶️ How to Run
1. Open project in Visual Studio
2. Build the solution
3. Run the program (Start button / F5)

---

## 📂 Project Type
Console Application (Beginner Level Project)
